## 3. 탭
### 3.1 개요 (설계안의 질문 네 개에 한 화면으로 답한다)
- **KPI 띠**(4칸, 누르면 해당 탭):
  1. 기간 사용액 $ + 직전 같은 길이 기간 대비 증감 % + 일별 스파크라인
  2. 남은 범위: 남은 점수 합 + 끝내는 데 드는 예상 $(프로젝트별 예상 합) 
  3. 5시간 구간: 지금까지 $ + 한도 대비 막대(보정 전이면 "추정" 배지) + 재설정까지 시간
  4. 주간 구간: 같은 형식, 진행 중 구간이 없으면 "—"와 이유
- **프로젝트 상태 표**("끝나가나?" + "끝내려면 얼마?"를 합침): 행 = ROADMAP 있는 프로젝트. 열: 상태 점·이름·단계 / 번업 미니 차트(가로 160px 이상, 범위·완료 두 선) / 완료·범위 점수 / 14일 범위 증가 vs 완료(↑↓ 화살표, growth > 1이면 경고색) / 대기 14일+ 개수 / 남은 예상 $ / 마지막 활동. 열 머리 누르면 정렬, 행 누르면 프로젝트 탭.
- **어디에 썼나?**: 프로젝트별 가로 막대(상위 8 + 기타) 옆에 모델별 비율 막대 하나. 막대 누르면 비용 탭이 그 프로젝트로 걸러져 열린다.
- **주의 목록**(있을 때만): 결정 뒤 14일 넘게 안 시작한 항목, 7일 넘게 멈춘 진행 중 프로젝트, 한도 도달 예상. 각 줄 누르면 해당 위치로.
### 3.2 프로젝트
- 머리: 이름, 단계, 마지막 Claude 활동, 기간 사용액, 점당 단가와 근거(프로젝트 / 전체 평균).
- **번업** 큰 차트: 범위·완료·남은 점수 선, 마우스 십자선과 그날 값 툴팁, 끌어서 확대·두 번 눌러 원래대로, 범위가 늘어난 날에 작은 표시(그날 추가된 항목 툴팁).
- **완료 구성 막대**(미리 계획한 일 vs 추가되자마자 처리한 일)와 14일 지표.
- **끝내려면**: 지금 시뮬레이터 유지. 항목은 제목만 한 줄로, 체크로 빼면 예상 $가 바로 바뀐다.
- **항목 표**: 열 = 상태 칩 / 제목(한 줄, 넘치면 말줄임) + {ID} 배지 / 크기 / 결정일 / 완료·자름일 / 걸린 날 / 묵은 날 / $. 상태 칩 필터(남음·진행 중·멈춤·완료·자름), 검색(/ 키), 열 정렬. 행을 누르면 아래로 펼쳐 **메모**(§6 note)와 날짜 이력을 보인다. 묵은 날 14일 이상은 경고색.
### 3.3 비용
- 일별 쌓은 막대: 쌓는 기준 전환(모델 / 프로젝트). 범례 눌러 계열 끄고 켜기. 막대에 마우스 → 그날 계열별 $ 툴팁. 막대 누르면 오른쪽(좁으면 아래) **그날 상세**: 프로젝트 × 모델 표와 토큰.
- 프로젝트별 막대(누르면 프로젝트 탭), 모델별 막대.
- "표로 보기" 전환과 **CSV 내려받기**(지금 걸러진 일별 행, Blob URL, 네트워크 없음).
- 다른 곳에서 실행된 세션 포함 여부는 전역 필터를 따른다.
### 3.4 한도
- 5시간·주간 구간 각각: 사용 $, 한도 대비 게이지(보정 값 있으면 실제 %, 없으면 추정 배지), 시간당 소모, 이 속도면 한도에 닿는 예상 시각(재설정 전에 닿으면 경고색), 재설정까지 시간.
- 보정 안내: `scopeburn calibrate <5h%> [weekly%]` 명령을 복사 버튼과 함께.
- 표본 수와 마지막 보정 시각.

## 4. 상호작용 공통
- URL 해시에 탭·프로젝트·기간·모델·포함 여부·쌓는 기준·항목 필터를 담고, 새로 열면 복원한다(지금 readHash/writeHash 확장).
- 키보드: 1~4 탭, / 검색, Esc 펼친 것·상세 닫기, ←→ 차트 십자선 이동(차트에 포커스 있을 때). 모든 버튼·행·막대는 Tab으로 갈 수 있고 `:focus-visible` 테두리.
- 툴팁: 한 가지 모양(작은 카드, 마우스 따라감, 화면 가장자리에서 뒤집힘). 터치에서는 누르면 고정, 바깥 누르면 닫힘.
- 실시간 모드: 데이터가 바뀌면 지금 탭·스크롤·펼친 행을 유지한 채 다시 그리고, 사이드바 아래 "실시간●"이 잠깐 깜빡인다(1회, 0.6초).
- 빈 상태: ROADMAP 있는 프로젝트가 없으면 개요 표 자리에 `scopeburn init` 안내. 기간에 기록이 없으면 "이 기간에는 기록이 없어요".

## 5. 시각 규칙 (차분한 분석 도구풍)
- 바탕 중립 회색 계열, 카드 = 1px 테두리·그림자 없음·모서리 8px. 간격은 4의 배수(4·8·12·16·24·32).
- 색 역할을 고정한다: 범위 = 회색, 완료 = 파랑(--s1), 남은 점수 = 주황(--s2), 경고 = --warning/--serious/--critical, 좋음 = --good. 계열 색(모델·프로젝트)은 지금 --s1~--s8 팔레트 순서. 강조색은 한 화면에 한 가지 의미로만.
- 글자: 시스템 글꼴 그대로(외부 글꼴 금지). 크기 단계 12 / 13 / 14 / 16 / 20 / 28. 숫자는 `font-variant-numeric: tabular-nums`, 금액·점수는 오른쪽 정렬.
- 차트: 격자선 가늘고 옅게, 축 글자 11px muted, 막대 위 모서리만 둥글게 2px, 애니메이션은 `prefers-reduced-motion`이 아니면 150ms 이내 페이드만.
- 어두운 테마는 같은 역할 색의 어두운 값(지금 변수 체계 유지).

## 6. 데이터 변경 (src/report-data.ts, src/report.ts)
- `ReportItem.title`: ROADMAP 줄에서 첫 ` — `(공백 전각 대시 공백) 앞까지. 그 뒤는 새 필드 `note: string | null`. 메모 안의 `@decided(...)` 같은 날짜 태그는 지금처럼 날짜 필드로만 쓰고 note에서는 지운다.
- `redact()`는 `note`를 `null`로 만든다(**공유용 페이지에 메모가 새면 안 됨**). 시험 필수.
- 개요 KPI의 "직전 같은 길이 기간 대비"는 이미 있는 `daily`로 화면에서 계산한다(데이터 변경 없음).
- `version`은 그대로 1(필드 추가만).
